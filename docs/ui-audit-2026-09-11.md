## Consistency principles

1. Primary actions should look like controls, not links: filled dark-green treatment, clear hover/focus/disabled states.
2. Secondary actions should use a consistent outlined treatment.
3. Text links should be reserved for navigation or low-emphasis tertiary actions such as opening a preview.
4. Native file inputs should receive a dedicated upload treatment; they should never visually collapse into body text.
5. Status text should not look clickable. Actions and statuses need visibly different affordances.
6. Every admin route should use the same admin shell/navigation rather than the public marketing header.
7. Dense tables should separate distinct data concepts into separate columns instead of concatenating labels and metadata.
8. Result counts should describe the active filter scope and use plain-language phrasing such as `Showing 3 of 5`.
9. Fallback/admin-only tools should not visually compete with the page's normal primary workflow.
10. Button labels should describe their actual destination or operation; misleading navigation copy is an audit defect, not merely a copy preference.
